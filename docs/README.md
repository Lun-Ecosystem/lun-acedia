# Documentation

Ce dossier décrit ce que le projet fait **aujourd'hui**, jamais son historique.

- `user/` : utilisation.
- `tech/` : architecture, contrats avec le core ou les satellites.
- `ops/` : déploiement, sauvegarde, retour arrière.
- `decisions/` : ADR propres au projet (une page, remplacés et jamais modifiés).
